# Gutter Sketch

Internal field tool for Sergeant Seamless Gutter Services. Not customer-facing.

An iPad + Apple Pencil app for drawing a gutter job on site: runs, downspouts, accessories, hazards, photos. It auto-counts the material list, writes the scope of work for each Jobber line item (Base and each Option) from the drawing, and exports a PDF (drawing + materials + photos) that gets attached to the Jobber quote. It also suggests a price for the Base and each Option from Ben's price book, which he keeps in a private Google Sheet (never in this repo). Jobber still holds the scope and price the customer sees and signs; the app's versions are suggestions until you paste them in.

## Where it runs

Live address (open in Safari on the iPad, then Share → Add to Home Screen):

https://sergeantseamless.github.io/gutter-sketch/gutter-sketch.html

All job data stays on the iPad (browser storage); no job, drawing or photo is sent anywhere. The one thing the app sends is the price book key, to read Ben's private sheet; the feed link and key live only on each iPad. The hosted file is just the app itself.

## Updating the app

1. Repo page → **Add file → Upload files**
2. Drop the new `gutter-sketch.html` (same filename — the home-screen icon depends on it)
3. Type a one-line commit message saying what changed (e.g. `v3 — bay miter fix`)
4. **Commit changes**. The site updates within a minute. On the iPad, force-quit the app and reopen.

To roll back: repo page → **commits** → pick the older version → view the file → download it → upload it again.

## Files

- `gutter-sketch.html` — the entire app, one file (HTML/CSS/JS, no build step, no backend); the brand badge and mascot are embedded inside it
- `icon-180.png` — the home-screen icon (badge on cream)
- `README.md` — this file

Keep it that way. No customer data, exports, credentials or other files belong in this repo — it is public.
